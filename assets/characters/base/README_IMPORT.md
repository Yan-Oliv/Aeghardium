# Character Import Notes

Para usar personagem real:
1. Coloque o modelo em `assets/characters/classes/mage.glb`.
2. O modelo deve estar em escala humana aproximada.
3. Preferencialmente com esqueleto/armature.
4. Preferencialmente com animacoes `Idle`, `Walk` e `Run`.
5. O ponto mais baixo do modelo sera alinhado automaticamente ao chao.
6. Se nao houver modelo, o jogo usa `PlaceholderHumanoid`.
