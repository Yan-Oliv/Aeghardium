# Equipamentos Pixel Art

Esta pasta guarda os sprites finais dos equipamentos 2D.

Enquanto os PNGs finais nao existem, o jogo usa dados procedurais em `res://scripts/2d/items/EquipmentVisualData.gd`.

## Categorias

- `weapons/`: espadas, cajados, arcos, adagas, machados.
- `shields/`: escudos e offhands.
- `armor/`: robes, peitorais, luvas, pernas e botas.
- `capes/`: capas e mantos.
- `accessories/`: aneis, amuletos e itens visuais menores.
