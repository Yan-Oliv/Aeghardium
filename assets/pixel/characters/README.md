# Pixel Character Sprites

Estrutura preparada para substituir os placeholders procedurais do `Player2DController`.

Padrao sugerido por classe:

- `idle.png`
- `walk.png`
- `portrait.png`

Direcoes esperadas futuramente: `down`, `up`, `left`, `right`.

Enquanto esses arquivos nao existirem, o player 2D gera sprites pixel art simples por codigo, com cores/silhueta por classe.
